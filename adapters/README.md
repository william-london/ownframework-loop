# Agent adapters

Adapters connect AI coding-agent hosts to the same OwnFramework Loop deterministic protocol.

- [`claude-code/`](claude-code/) — stable reference adapter; preserves the public Claude plugin experience.
- [`codex/`](codex/) — experimental Agent Skills adapter; live host verification remains separate evidence.

Adapters do not own approval, lifecycle state, repair counters, candidate SHA identity, verdict identity, or promotion.

See [`docs/architecture/ADAPTER_CONTRACT.md`](../docs/architecture/ADAPTER_CONTRACT.md) and [`docs/ADAPTER_DEVELOPMENT.md`](../docs/ADAPTER_DEVELOPMENT.md).
