# Portable review adapter

Claim through the core, consume `ofloop review prepare`, consume
`ofloop review assessment-skeleton`, inspect the returned exact candidate
read-only, cover every AC/non-goal, fill only the returned pass-scoped semantic
assessment, then call deterministic `ofloop review finalize`.

Never choose candidate/worktree identity, edit source, write authoritative
protocol artifacts, approve, push, merge, deploy, publish, mutate remotes, or
reset budgets. PROGRAM advancement remains core-owned.
