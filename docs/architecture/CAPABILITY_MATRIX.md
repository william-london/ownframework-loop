# Adapter capability matrix

| Capability | Claude Code | Codex |
|---|---|---|
| Maturity | Stable / reference | Experimental |
| Shared work-packet protocol | Yes | Yes |
| Human TTY approval gate | Core-owned | Core-owned |
| Exact candidate SHA | Core-owned | Core-owned |
| Exact-SHA review contract | Yes | Yes |
| Core-owned repair budget | Yes | Yes |
| Agent Skills | Yes | Yes |
| Native custom agents/subagents | Yes | Not claimed |
| Native deterministic hooks | Yes | Not claimed |
| Hard command interception | Yes | Not claimed |
| Managed OwnFramework installer | Yes | Not yet |
| Live host verification | Yes | Pending real Codex proof |

Agent-agnostic core does not imply identical host capabilities. An adapter may be protocol-compatible without being hardened to the same level as the Claude Code reference adapter.
